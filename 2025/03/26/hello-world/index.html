Hello World

2025-03-26 约 2 分钟 编程
编程 Hexo

这是这个博客的第一篇文章。与其照抄 Hexo 的默认模板，不如拿它当一次真实的练手：从零把站点跑起来，再把它改成自己想要的样子。

为什么要自己写一遍

Hexo 生成的默认主题开箱即用，但它把几乎所有东西都藏在模板里。想换个配色、加个板块、改一下文章卡片，改起来反而绕。所以这次我干脆把生成的静态产物直接重写了一遍 —— 结构、样式、交互全部自己控制。

能用默认的，就先跑起来；要长期维护的，还是得自己握在手里。

几个常用命令

Hexo 的日常其实就四条命令，记住基本就够用了。

新建文章

会在 source/_posts/ 下生成一份带 front-matter 的 Markdown。

本地预览

默认起在 http://localhost:4000，改文件会热更新。

生成静态文件

产物落在 public/，这一步决定了最终上线的样子。

一键部署

配合 _config.yml 里的 deploy 配置，可以直接推到 GitHub Pages。

这套界面的取舍

整体走扁平化路线：去掉渐变阴影和拟物质感，靠留白、层级和一点点色彩对比来撑结构。

  • 颜色：只保留一个主色（靛紫）和一个点缀色（暖橙），其余全部交给中性灰度。
  • 圆角：统一 10px / 16px 两档，不做大小混用。
  • 动效：只保留位移和透明度过渡，时长控制在 250ms 以内，不喧宾夺主。
  • 深色模式：用 CSS 变量整套切换，不写第二份样式表。
